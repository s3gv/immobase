## English

ImmoBase is licensed under the **GNU Affero General Public License v3.0 or later**. Contributions are welcome.

### Licensing of contributions

What goes in comes out under the same terms: by opening a pull request you contribute your work under **AGPL-3.0-or-later**, the license the project itself uses. There is no contributor license agreement to sign and nothing to print or send.

You keep the copyright in your contribution. New source files carry an SPDX header — see [docs/licensing/header-policy.md](docs/licensing/header-policy.md).

### Contributions you do not fully own

Only submit work whose copyright you actually hold.

If a change contains code you did not write — a snippet from another project, a vendored file, generated output that carries someone else's license — **do not open a pull request for it**. Open an issue first and state where the code came from and under which license. Third-party code may still be usable, but it has to be tracked separately from your own contribution and cannot be contributed by you.

The same applies to code you wrote for an employer or client who owns the result.

### Code of conduct

Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

### Security issues

Do not report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).

### Project status

ImmoBase is being rebuilt from scratch and is not yet usable. Until the first release, external pull requests are unlikely to be merged — the architecture is still moving. Issues and discussion are welcome regardless.

## Mitwirken an ImmoBase

> **Hinweis:** Dieser deutsche Abschnitt ist eine unverbindliche Lesehilfe.

ImmoBase steht unter der **GNU Affero General Public License v3.0 oder später**. Beiträge sind willkommen.

### Lizenz für Beiträge

Was hineingeht, kommt zu denselben Bedingungen wieder heraus: Mit einem Pull Request stellst du deine Arbeit unter **AGPL-3.0-or-later**, also unter die Lizenz des Projekts. Es gibt keine Contributor License Agreement zu unterschreiben, nichts auszudrucken und nichts zu verschicken.

Dein Urheberrecht bleibt bei dir. Neue Quelldateien tragen einen SPDX-Header — siehe [docs/licensing/header-policy.md](docs/licensing/header-policy.md).

### Beiträge, die dir nicht vollständig gehören

Reiche nur Arbeit ein, deren Urheberrecht du tatsächlich hältst.

Enthält eine Änderung fremden Code — ein Schnipsel aus einem anderen Projekt, eine mitgelieferte Datei, generierte Ausgabe unter fremder Lizenz — **öffne dafür keinen Pull Request**. Melde dich zuerst über ein Issue und nenne Herkunft und Lizenz. Fremder Code ist unter Umständen trotzdem verwendbar, muss aber getrennt von deinem eigenen Beitrag nachgehalten werden.

Dasselbe gilt für Code, den du für einen Arbeitgeber oder Kunden geschrieben hast, dem das Ergebnis gehört.

### Projektstatus

ImmoBase wird gerade von Grund auf neu gebaut und ist noch nicht benutzbar. Bis zum ersten Release werden externe Pull Requests eher nicht gemergt — die Architektur bewegt sich noch. Issues und Diskussion sind trotzdem willkommen.
